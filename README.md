# দুয়েরপল্লী সার্ব্বজনীন দুর্গাপূজা কমিটি — অফিসিয়াল পোর্টাল ও শারদ স্মারক
### Duyerpally Sarbojanin Durgotsav Samiti (70th Year · 1956 - 2026)

An official, responsive web portfolio built with **React**, **TypeScript**, and **Vanilla CSS Design System**, engineered using the aesthetic strategy, procedural vector mathematics, and radical local-first privacy inspired by **PUJO SMRITI**.

## 🏛️ Core 4-Page Information Architecture

### 1. ভূমিকা ও পরিচিতি (Page 1: Introduction & 52-Year Legacy)
- **ঐতিহাসিক পটভূমি (1974 - 2026)**: অর্ধশতাব্দীর গৌরবোজ্জ্বল যাত্রা ও সর্বজনীন সম্প্রীতি।
- **ভাবনা ২০২৬ (Theme)**: *"আলোকবর্তিকা — অন্ধকারের বুকে এক চিলতে আলোর প্রার্থনা"* (The Torch of Hope).
- **মূল আদর্শ (4 Pillars)**:
  1. প্লাস্টিকমুক্ত পরিবেশবান্ধব মণ্ডপ (Zero Plastic Eco-Architecture)
  2. কুমোরটুলির সনাতনী একচালা রূপ (Traditional Kumartuli Idol)
  3. সর্বজনীন অন্নসেবা (Community Kitchen serving 4,000+ meals)
  4. সমাজকল্যাণ ব্রত (Blood donation camp & clothing donation)
- **ইন্টারেক্টিভ মঙ্গল প্রদীপ প্রজ্জ্বলন (Light a Diya)**: ভক্তদের ভার্চুয়াল প্রদীপ প্রজ্জ্বলন কাউন্টার ও গোল্ডেন কনফেটি অ্যানিমেশন।

  - সন্ধিপূজার ১০৮ প্রদীপ ও ১০৮ পদ্মের পবিত্র ক্ষণ (রাত ০৯:১২ - ১০:০০)
